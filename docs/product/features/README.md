# Features

## Product rules (all pages)

1. **Current state only.** Each flow run replaces its rows; expired rows are deleted. No history, no day picker.
2. **Valid items only.** Discarded, closed and past items never show.
3. **Every page shows the last run of its flows:** OK (green) or Failed (red), with the time. Failed links to Errors.
4. **Telegram = errors only.** Each flow stops sending results the day its page goes live.
